## Подготовка

По разрешённому пользователем варианту выполнена векторная реконструкция: субпиксельная трассировка и упрощение с допуском 0,16 исходного пикселя. Сине-фиолетовые градиенты восстановлены по цветовым выборкам из исходников. Это SVG-экспорт по изображениям, а не исходный вектор автора; попиксельное совпадение градиента с JPEG/PNG не заявляется.

Геометрия A/D одинакова в двух исходниках. Для обеих тем взят чистый контур из светлого файла: низкий контраст и артефакты у края D в тёмном изображении иначе дают отверстия. Цвет L/I/N и подписи извлечён отдельно: #16192C / #F8F7FC. Пропорции и интервалы сохранены. Генерация изображений не применялась; оригиналы не редактировались.

Воспроизведение: `tools/trace-approved-logo.py` создаёт SVG (Pillow/numpy), `node tools/export-logo-png.mjs` экспортирует PNG через локальный Chrome. Для запуска сайта Python не требуется.

## Подключение и проверки

`src/config/assets.ts` хранит оба пути; общий `src/components/Logo.tsx` выбирает вариант из настроек темы во всех шести маршрутах. Смена темы меняет src без навигации или перезагрузки; выбор восстанавливается после reload.

Снимки: `qa/logo/both-themes.png`, `qa/logo/header-{320,390,768,1440}-{light,dark}.png`. На мобильных сохранён масштаб шапки; контуры подписи остаются векторными и при увеличении не распадаются на пиксели. Эмуляция ширины экрана в Chrome не заменяет проверку на физическом телефоне.

`tests/logo.spec.ts` проверяет прозрачность всей границы и просветов, цвета букв, наличие подписи, пропорции, смену темы без замены документа, сохранение выбора и отсутствие переполнения. Общая матрица проверяет шесть страниц, RU/DE/EN и обе темы на 11 ширинах.

Итог: **96 тестов пройдены (2,1 мин)**, typecheck/lint/build пройдены. PNG независимо проверены как RGBA 3860×1092 с альфой 0–255 и прозрачной границей. Копии обоих исходников побайтно совпадают с вложениями.
