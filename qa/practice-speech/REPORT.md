# Practice for Everyday Life — озвучивание RU / DE / EN

Дата: 19 октября 2026. Исправление относится только к Practice. Платные API, ключи, распознавание речи и микрофон не добавлялись.

## Установленная причина

До изменения кода проверен `speechSynthesis.getVoices()` в установленном Chrome (автоматизированный отдельный профиль). Он вернул только:

- Microsoft Irina — `ru-RU`, локальный системный голос, по умолчанию.
- Microsoft Pavel — `ru-RU`, локальный системный голос.

Голосов `de-*` и `en-*` в этом браузере не было. Это подтверждено свежим `voices-before.json`, а не предположением по языку интерфейса. Привязка языка в прежних кнопках была корректной; отсутствие DE/EN в API — конкретная проверенная причина их молчания. Сайт не может создать отсутствующий системный голос через Web Speech API.

Старый выбор использовал первый подходящий голос в списке, без приоритета Natural/Neural. Скорость была 0,9. При движке, не приславшем `end/error`, активная кнопка могла оставаться активной без ограничения времени. Существовавшее ожидание `voiceschanged` сохранено по смыслу и усилено: проверяется именно нужный язык, есть периодический опрос и финальное чтение перед таймаутом.

## Что изменено

`src/speech/browser-speech.ts` — единый контроллер для всех динамиков Practice. Входная запись содержит `text`, явный `language` и необязательный ID `voice`; выход — состояние, активная кнопка, отсутствующие языки и структурированная ошибка. React-код отображает результат и не выбирает язык по интерфейсу.

`src/speech/voices.ts`:

1. Сначала фильтрует голоса по языку (`ru`, `de`, `en`), включая нормализацию `_`/`-`.
2. Учитывает сохранённый ручной выбор только среди голосов того же языка.
3. В автоматическом режиме предпочитает Natural/Neural/Enhanced/Premium по доступным метаданным названия; затем браузерные голоса Google, нужный регион, системный голос по умолчанию и локальность как небольшой критерий при прочих равных.
4. Региональные предпочтения: RU — ru-RU; DE — de-DE, затем de-CH/de-AT; EN — en-GB, затем en-US. Natural/Neural того же языка может получить приоритет над обычным голосом другого региона.
5. Устанавливает `utterance.lang`: ru-RU, de-DE, en-GB или en-US. Русский голос никогда не подставляется для немецкого/английского текста.

Web Speech API не предоставляет объективной оценки естественности. Проверка названия — эвристика после фильтра языка, а не гарантия качества. Ручной выбор позволяет пользователю сравнить доступные голоса на своём устройстве.

Параметры: `rate = 0.98`, `pitch = 1`, `volume = 1`. Исходный текст сохраняется с кириллицей, пунктуацией, ä/ö/ü/ß; транслитерации нет.

## Управление воспроизведением

- Повторный клик по активной кнопке останавливает текущую очередь.
- Другая кнопка прерывает старую речь и начинает новую. Одновременно передаётся один utterance.
- Смена видимых языков, ситуации или уход со страницы отменяют текущую/ожидающую речь.
- Поколения запросов, AbortController и очистка обработчиков исключают запуск старой очереди после отмены и запоздалых `end/error`.
- Список голосов прогревается при входе, обновляется через `voiceschanged` и опрос. Ожидание недостающего языка ограничено четырьмя секундами на окно загрузки очереди; наличие одного RU-голоса не считается готовностью DE/EN.
- При сетевой ошибке/недоступности выбранного голоса пробуется другой доступный голос того же языка (максимум три кандидата); переход сообщается пользователю.
- Запрет звука, отсутствие API, ошибки движка и таймауты имеют явное сообщение и освобождают кнопку.
- Есть контроль отсутствия запуска (8 секунд на кандидата, если движок не сообщает, что говорит) и отсутствия завершения (зависит от длины текста, 15–120 секунд). Это не запускает несколько потоков речи.

## Минимальное дополнение к интерфейсу

Свёрнутый блок «Голоса озвучивания» над существующими тремя панелями. В нём — отдельный выбор RU/DE/EN из реального списка браузера. Сохраняется в `linad.speech.voices.v1`; существующие настройки видимости языков, сохранённые слова/фразы, результаты и прогресс не переписываются. Если localStorage запрещён, выбор работает в текущей вкладке с сообщением об отсутствии сохранения.

Категории, ситуации, баннер, карточки, динамики, переводы, диалоги, словарь, Header/Footer и глобальная палитра сохранены. Добавлены только стили блока выбора, scoped внутри `.practice-workspace`.

Learning by Level продолжает использовать прежний `practice/speech.ts` и `useLevelSpeech.ts` без изменений. Новый независимый контроллер пригоден для подключения туда позже; сейчас оно не выполнялось.

- Быстрые RU→DE→EN, повторный клик, остановка, смена ситуации/видимых языков и устаревшие callbacks.
- Ошибки Natural-голоса с переходом только на тот же язык, запрет звука, молчащий/незавершающийся движок, исключения API и отсутствие API.

## Что требуется для DE/EN на проверенном устройстве

В Windows необходимо добавить/включить голоса Text-to-speech для German и English и перезапустить браузер. Проверка результата — появление этих голосов в раскрывающемся списке LINAD. Встроенные Natural-голоса Narrator/Read Aloud не обязательно доступны JavaScript: ориентироваться нужно именно на список, возвращённый браузером. Сам сайт не устанавливает языковые пакеты и не меняет настройки Windows.

Официальные материалы:

- [Web Speech API: список и свойства голосов, события, ошибки](https://webaudio.github.io/web-speech-api/).
- [MDN: getVoices и асинхронное обновление](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices).
- [Microsoft: настройка языков и компонентов Text-to-speech Windows](https://support.microsoft.com/en-us/windows/hardware/input-devices/manage-the-language-and-keyboard-input-layout-settings-in-windows).

Никакой внешний TTS endpoint не вызывается. Онлайн-голос, если его предоставляет сам браузер, может зависеть от сети и правил браузера; у LINAD нет отдельного платного API, ключа или подписки.
