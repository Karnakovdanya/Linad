# LINAD — 60 ситуаций Practice for Everyday Life

Добавлены 54 ситуации в девяти категориях. Шесть утверждённых ситуаций «Врач и здоровье» сохранены без изменений. В каждой из десяти категорий теперь по шесть ситуаций в заданном порядке.

В каждой ситуации — 15 фраз, три диалога по 4–8 реплик и 20 слов. Всего: **900 фраз, 180 диалогов, 1200 слов**, с переводами RU / DE / EN. Новые диалоги содержат по четыре реплики и соответствующие роли участников. Новое содержание имеет статус редакционного черновика для проверки владельцем проекта.

Материалы отделены от компонентов. Первый набор фраз каждой ситуации также используется в её диалогах; ответы второго участника и названия диалогов написаны отдельно. Это позволяет править выражения согласованно. Идентификаторы сохранений включают категорию, ситуацию, тип элемента и ID записи.

## Озвучивание

Интеграционные проверки новых категорий подтверждают соответствие текста и кодов `ru-RU`, `de-DE`, `en-GB` для фраз, слов, отдельных реплик и целых диалогов. Сама реализация синтеза речи сохранена.

Реальная проверка Chrome на этом компьютере обнаружила только Microsoft Irina и Microsoft Pavel (`ru-RU`). Русское воспроизведение выдаёт события начала и завершения во всех трёх блоках. Немецкие и английские голоса недоступны; интерфейс показывает существующее понятное сообщение вместо подмены голоса русским. Реальное звучание DE / EN на этой системе проверить нельзя до появления соответствующих голосов. Платные API не используются.
