# Контрольные скриншоты фазы A

Это рабочий каркас, а не утверждение финального дизайна главной/автора. Подробности проверки и отличия — `RESPONSIVE_QA.md` в корне проекта.

Имена `home-{width}-{locale}-{theme}.png`: width 390/1440, locale ru/de, theme light/dark. Файл `author-390-ru-light.png` показывает заготовку автора с утверждённым портретом.

Все файлы сделаны реальным браузером из production-сборки. Это снимки первоначальной фазы A. Актуальные снимки главной после добавления EN находятся в соседнем каталоге `qa/locales-contacts/`; они обновляются тестами. Снимок автора здесь также обновляется тестом touch-навигации.
