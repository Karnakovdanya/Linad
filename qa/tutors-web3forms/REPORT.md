# LINAD Tutors — Web3Forms

20 октября 2026.

## Готово

- Обе существующие формы отправляют JSON непосредственно из браузера на `https://api.web3forms.com/submit` с предоставленным публичным Access Key.
- Все шесть преподавателей используют один ключ, который, по данным владельца, привязан к `danikkarnakov@gmail.com`. Поле произвольного получателя/CC не передаётся.
- Заявка ученика включает имя/email, выбранного преподавателя и его ID, язык, уровень, цель, время и сообщение. Тема — `LINAD — Запрос на занятие — [Имя преподавателя]`.
- Анкета кандидата включает все поля существующей формы, в том числе выбранные языки/уровни, образование, опыт, историю и дополнительную информацию. Тема — `LINAD — Заявка преподавателя — [Имя кандидата]`.
- `email` и `replyto` содержат email заявителя. Уведомление отправляется от имени LINAD Tutors. Темы и подписи полей для административной почты остаются понятными на русском независимо от интерфейса RU/DE/EN.
- Подтверждение показывается только при успешном HTTP-ответе и JSON `success: true`. Отдельный ID письма Web3Forms не требуется и не выдумывается; в памяти остаются только тип квитанции, ID выбранного преподавателя и время подтверждения.
- Добавлена проверка payload до отправки, сохранена проверка обязательных полей/email/длин, блокируются неподходящие язык/уровень/ID и переносы строк в теме. Есть синхронная блокировка повторного нажатия, отключение полей/кнопки на время запроса и тайм-аут 20 секунд.
- Ошибки API, невалидный JSON, `success: false`, HTTP 429 и сетевые ошибки не дают ложного успеха. Поля остаются, ручной повтор доступен, автоматических повторов POST нет. Нельзя гарантировать отсутствие дубля после обрыва связи, если сервис уже принял предыдущий запрос.
- Базовый антиспам — скрытый checkbox `botcheck`, локальная блокировка заполненного honeypot и встроенная фильтрация Web3Forms. CAPTCHA/платные функции не подключались. Это базовая защита, не глобальный rate limiter приложения.
- Серверная интеграция Resend убрана; её ключи, домен, Origin и флаг верификации больше не нужны. Формы готовы к использованию на существующем статическом сайте. Дизайн, карточки, порядок преподавателей, фото и стили не менялись.

## Проверка владельцем

1. Открыть профиль любого преподавателя → «Запросить занятие», заполнить действующий email и все обязательные поля, отправить тестовую заявку.
2. Открыть «Стать преподавателем LINAD», заполнить анкету с явной отметкой технической проверки, отправить.
3. В обоих случаях проверить `danikkarnakov@gmail.com` (входящие/спам), разные темы, все поля и адрес Reply-To. При включённых ограничениях домена/CAPTCHA в аккаунте Web3Forms сверить их с используемым сайтом.

Подробная инструкция: [TUTORS_EMAIL_SETUP.md](../../TUTORS_EMAIL_SETUP.md). Контракт проверен по [официальному API Web3Forms](https://docs.web3forms.com/getting-started/api-reference), включая `subject`, `email`, `replyto`, `botcheck` и `success`.
