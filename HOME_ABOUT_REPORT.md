# Главная LINAD: информационный блок и размер Лина

Выполнено 21 октября 2026 года.

## Изменения

- Между тремя карточками главной страницы и существующим блоком обучения добавлен «Что такое LINAD?». Слева — заголовок с синим LINAD и два абзаца, справа — шесть преимуществ в две колонки. Кнопок и отдельной страницы нет.
- Добавлены переводы RU/DE/EN и оформление через существующие переменные LINAD. На планшете описание находится над преимуществами, на телефоне преимущества идут одной колонкой.
- Увеличено только первое приветственное изображение помощника: с 216 до 330 px на компьютере и с 144 до 280 px на телефоне, с ограничением по доступной ширине. Полный исходник и его пропорции сохранены. Остальные изображения и поведение помощника не менялись.

## Файлы приложения

Изменены:

- `src/pages/HomePage.tsx` — импорт и вставка нового компонента.
- `src/assistant/lin.css` — только две величины ширины приветственного изображения.

Добавлены:

- `src/components/HomeAbout.tsx` — информационный блок.
- `src/i18n/home-about.ts` — тексты на трёх языках.
- `src/styles/home-about.css` — изолированные стили и адаптивность.

Проверка исходников подтверждает: все остальные 156 существующих файлов приложения сохранены. Существующие блоки главной страницы и их CSS не изменены. SQL, настройки Supabase и новые зависимости не требуются.

## Проверки

- `npm.cmd run build` — успешно. Остаётся прежнее предупреждение Vite о JS-файле больше 500 kB.
- `npm.cmd run lint` — успешно.
- `npm.cmd test -- tests/home-about.spec.ts` — 8 тестов успешно. RU/DE/EN × обе темы, ширины 1440, 1024, 768, 390 и 320 px; порядок блоков, отсутствие лишних переходов, переполнения и обрезанного текста; переключение языка/темы; размер и пропорции Лина.
- `npm.cmd test -- tests/lin-assistant.spec.ts` — 13 тестов успешно. Все восемь вопросов, локальный поиск, реальные переходы, Escape и клавиатура, обе темы, три языка, компьютер и телефон, доступность кнопки на существующих страницах.
- Визуально проверены скриншоты блока на компьютере и телефоне, в светлой и тёмной темах. Также проверен фактический сайт на порту 5173 в браузере Codex.

Тестовые файлы: `tests/home-about.spec.ts`, `tests/lin-assistant.spec.ts`, `tests/protected-source.ts`. Исторические проверки исходников учитывают только точные разрешённые изменения; отдельная проверка нового задания сравнивает их с исходным кодом до изменений.
