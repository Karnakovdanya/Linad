# LINAD — контакты автора

В блоке «Давайте на связи» добавлены WhatsApp и Behance. Порядок: Telegram, GitHub, LinkedIn, WhatsApp, Behance. Используются прежние классы контактных кнопок и существующие цвета/шрифты. Пять кнопок помещаются в одну строку на широком экране; при меньшей доступной ширине переносятся.

Email вынесен под кнопки: `danikkarnakov@gmail.com`, с явной ссылкой `mailto:` и отдельной кнопкой копирования. Clipboard API вызывается только после нажатия кнопки; почтовая программа автоматически не открывается. Успех показывается только после успешного завершения операции, отказ/отсутствующий API сопровождается понятным предложением скопировать адрес вручную. Подписи и обратная связь переведены на RU/DE/EN.

Существующие Telegram/GitHub/LinkedIn URL сохранены. Новые внешние ссылки открываются в новой вкладке с `noopener noreferrer`; номер WhatsApp не выводится в тексте. Общий email в других разделах оставлен прежним, как требуется ограничением на область изменений.

Изменены:

- `src/pages/AuthorContent.tsx` — подключение изолированного блока контактов.
- `src/styles/author.css` — перенос пяти кнопок и отдельная строка Email; остальные правила сохранены.
- `src/config/contacts.ts` — WhatsApp и отдельный email для блока автора.
- `src/components/ContactIcon.tsx` — соответствие WhatsApp локальной SVG-иконке.
- `src/i18n/author-messages.ts`, `src/i18n/messages.ts` — только новые подписи.

Добавлены `src/pages/AuthorContacts.tsx` и `public/assets/contact-icons/whatsapp.svg`. Иконка взята из той же [официальной Bootstrap Icons 1.13.1](https://github.com/twbs/icons/blob/v1.13.1/icons/whatsapp.svg), которую сайт уже использует; лицензия MIT уже включена в папку иконок. Новых библиотек нет.
