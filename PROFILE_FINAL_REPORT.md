# LINAD — финальная главная профиля и сохранение настроек

## Результат

Сохранение фамилии, языка и темы исправлено. Главная профиля поддерживает оба утверждённых состояния и промежуточное состояние с одним языком. Header, Footer, Home, Tutors, Web3Forms, маршруты и исходники логики курсов не изменены.

### Настройки

- Тема и интерфейс применяются при «Сохранить» сразу. Форма блокирует повторные нажатия и сообщает успех только после ответа Supabase.
- При недоступной SQL-схеме персональные сведения реально сохраняются через Supabase Auth metadata. Это позволяет использовать уже существующий аккаунт до ручной установки таблиц.
- После настройки SQL сведения автоматически переносятся в RLS-таблицу `profiles`. Перенос не затирает более новую запись, появившуюся после чтения.
- Ошибки прав доступа и сети не выдаются за успех; поля формы не сбрасываются. Профиль загружается независимо от ошибки синхронизации курсов.
- При восстановлении страницы ожидается загрузка сохранённой сессии, прежде чем решать, нужен ли переход к входу.
- Блок «Языки и уровень владения» удалён из настроек.

### Главная профиля

- Сохранён чистый фон горного озера и аватар с изменением фотографии. Добавлены приветствие, полное имя и полупрозрачная цитата.
- В баннере есть карточка «Добавить язык для изучения». Диалог позволяет выбрать German/English, явно указать A1–C1, изменить уровень или удалить язык. Выбор не делается автоматически.
- Без языков показываются карточка добавления и пустое обучение; при одном языке — его карточка и добавление второго; при двух языках — две карточки без кнопки добавления.
- Цель задаётся и удаляется пользователем в отдельном диалоге. Без цели показано «Не выбрана». Уровень цели и самооценка не считаются подтверждёнными результатами курса.
- Серия дней рассчитывается по реальным временным меткам учебной активности. Учитываются местные календарные дни, дубликаты, пропуски и переходы летнего времени. Редактирование профиля не увеличивает серию.
- История временных меток хранится в документе аккаунта, отдельно от логики выполнения курсов. Старый формат документа поддерживается; при объединении данные сохраняются.
- Под баннером расположен отдельный блок «Моё обучение» с предоставленными фотографиями Берлина/Лондона и настоящими уровнем курса, прогрессом и продолжением обучения.
- Ниже сохранены реальная статистика, общие с Home Telegram-карточки и действительная последняя активность.

**Полную облачную синхронизацию учебного прогресса и работу Storage на действующем сервере нельзя считать проверенными:** API таблицы профиля продолжает возвращать `PGRST205`. Персональное сохранение работает через настоящий Supabase Auth. Для остальной схемы нужен административный SQL владельца.

## SQL и ручные действия

Выполнить целиком **`supabase/INSTALL_LINAD_ACCOUNTS.sql`** в SQL Editor проекта. Он объединяет три миграции в одной транзакции, сохраняет записи и допускает повторный запуск.

Новая миграция: `supabase/migrations/202610210002_profile_goals.sql` (`study_goal`, `profile_saved_at`). Если первые две уже установлены, достаточно новой.

Точная инструкция и проверки: [PROFILE_FINAL_SETUP.md](PROFILE_FINAL_SETUP.md). После применения нужно проверить настоящие записи/чтение прогресса и Storage, вход на втором устройстве и изоляцию двух пользователей. Клиент не содержит административных ключей.

- **49 автоматических проверок кабинета прошли** в совместном запуске `account.spec.ts`, `profile-update.spec.ts`, `profile-final.spec.ts`.
- Дополнительно после компактной корректировки карточек повторены проверки адаптивности, склонений серии и исходников.

- `node qa/profile-final/check-migrations.mjs` — три миграции и единый установщик выполнены и повторно применены в локальном PostgreSQL/WASM.
