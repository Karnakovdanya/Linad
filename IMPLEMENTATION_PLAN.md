## Архитектура

- Приложение в корне открытой папки; `LINAD/` остаётся неизменяемым пакетом источников.
- Vite + React + TypeScript, React Router HashRouter, обычный CSS с утверждёнными токенами. Бесплатные зависимости; окружение Windows — Node.js 24 LTS или новее.
- Hash-маршруты: `/`, `/learn`, `/tutors`, `/telegram`, `/profile`, `/author`; неизвестный адрес показывает 404. На GitHub Pages адрес имеет вид `/имя-репозитория/#/learn`; `base: './'` поддерживает вложенный путь.
- Общая оболочка: шапка, мобильное меню, переключатели RU/DE/EN и темы, main, футер. UI-локализация типизирована; язык обучения отдельно от языка интерфейса.
- Настройки: `linad.preferences.v1`, версия схемы 1, проверка входных данных, обработка повреждённого/недоступного localStorage. Ошибка сохранения видима пользователю. Синхронизация настроек между вкладками одного браузера через storage event.
- Будущее учебное состояние: отдельный версионированный ключ/адаптер. В фазе A нет фиктивного прогресса, аккаунтов или заявок.
- Одобренные PNG копируются побайтно в `public/assets/`. Фото не перекрашиваются; локальные overlay обеспечивают читаемость. По новому поручению белый фон логотипа удаляется SVG-фильтром при отображении исходного растра, без перерисовки букв; тёмная версия сохраняет читаемость.
- Контакты задаются только в `src/config/contacts.ts`: Telegram проекта/автора, Instagram, GitHub, Behance, email и LinkedIn. Шесть предоставленных контактов подключены; Instagram остаётся `null`. `ContactLink` читает конфигурацию, поддерживает иконки и emailDraft. Внешние web-ссылки открываются безопасно в новой вкладке; почтовые ссылки открывают приложение без имитации отправки.

- Браузер: 320/360/375/390/430/768/820/1024/1280/1440/1920 px; RU/DE/EN × light/dark. Все будущие разделы/формы/сообщения, включая регистрацию и помощник, сразу переводятся на все три UI-языка. Реально выполненные проверки и ограничения — в `RESPONSIVE_QA.md`.
